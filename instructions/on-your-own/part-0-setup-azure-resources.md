# Part 0: Setup Azure Resources

In this part, we will set up the necessary Azure resources required for our for this lab.

1. Open the [Azure Portal](https://portal.azure.com) in your web browser.

1. Sign in to the portal using your Azure credentials.

    > [!Hint]
    > Use the same account you used when you logged in with `az auth login`.

1. Click on the **Sign in** button to proceed with the login process.

1. Once logged in to the Azure portal landing page, select **View all resources**.

    ![View All Resources](/instructions/media/all-resources.jpg)

1. Observe the two Azure resources, we'll be using these during the course of this lab:

    - Azure OpenAI instance
    - Azure HorizonDB database instance

    ![Resource Check](/instructions/media/azure-resources.png)
